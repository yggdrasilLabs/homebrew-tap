# YggdrasilLabs Tap

## How do I install these formulae?

`brew install yggdrasillabs/tap/<formula>`

Or `brew tap yggdrasillabs/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "yggdrasillabs/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
